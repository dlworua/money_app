🎨 Mont 앱 아이콘 생성

더 임팩트있고 눈에 확 띄는 디자인!

✨ 새로운 디자인 특징

  • 강렬한 3색 그라데이션 (cyan → teal → emerald)
  • 발광(glow) 효과로 생동감 추가
  • 동전 외곽과 산(M)이 완벽하게 연결
  • 여백 없는 깔끔한 통합 디자인
  • 정상 점 하나로 심플하게
💡 사용 방법:

1. PNG 파일을 다운로드하세요
2. assets/images/mont_icon.png로 저장
3. flutter pub run flutter_launcher_icons 실행
4. 앱 재빌드하면 새 아이콘 적용!
