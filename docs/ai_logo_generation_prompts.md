## 🚀 AI 생성 사이트별 가이드

### 1. Midjourney (Discord)
```
/imagine prompt: [위 프롬프트 중 하나 복사]
Parameters:
- --ar 1:1 (정사각형)
- --v 6 (버전 6)
- --style raw (스타일화 최소)
- --s 50 (stylize 값 낮게)
```

**Tips:**
- 여러 번 생성해보고 마음에 드는 것 선택
- Variations 버튼으로 변형 시도
- Upscale로 고해상도 생성

### 2. DALL-E 3 (ChatGPT Plus)
```
위 프롬프트를 ChatGPT에 그대로 입력
"Create a [프롬프트 내용]" 형식으로 시작
```

**Tips:**
- "더 미니멀하게" "더 클린하게" 같은 피드백 가능
- 여러 버전 요청 가능
- 바로 편집/수정 요청 가능

### 3. Adobe Firefly
```
프롬프트 입력 후:
- Style: Graphic
- Color & Tone: Vibrant
- Composition: Centered
```

### 4. Leonardo.ai
```
Model: Leonardo Phoenix
Style Preset: Graphic Design
Resolution: 1024x1024
Guidance Scale: 7
```

## 🎯 최종 선택 가이드

생성된 이미지 중 선택 기준:
1. ✅ 작은 크기(60x60)에서도 선명한가?
2. ✅ 한눈에 "금융 앱"임을 알 수 있는가?
3. ✅ 트렌디하고 모던한가?
4. ✅ 다른 앱들과 구별되는가?
5. ✅ 브랜드 컬러(Teal)가 잘 표현되었는가?
