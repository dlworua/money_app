## 📐 로고 디자인 가이드

### 컨셉 1: 미니멀 산(M) 심볼
```
캔버스: 1024 x 1024 px
배경: Teal → Dark Teal 그라데이션 (좌상단→우하단)
라운드: 227px (iOS 표준)

심볼 디자인:
┌─────────────────────┐
│                     │
│        /\  /\       │  ← M자 형태의 이중 산봉우리
│       /  \/  \      │     중앙에 작은 원(목표점)
│      /        \     │
│     M          M    │
│                     │
└─────────────────────┘

세부 사항:
- 선 두께: 48px
- 선 색상: White (#FFFFFF)
- 선 끝: Round cap
- 선 연결: Round join
- 중앙 포인트: 지름 40px 원
- 여백: 상하좌우 180px
```

### 컨셉 2: 타이포그래피 중심
```
캔버스: 1024 x 1024 px
배경: Teal 단색

텍스트:
- 폰트: Pretendard ExtraBold 또는 SF Pro Display Heavy
- 글자: "M" 또는 "몬트"
- 크기: 600px (M 하나) 또는 360px (몬트)
- 색상: White
- 정렬: 중앙
- 커닝: -5% (타이트하게)

추가 요소:
- M 상단에 작은 화살표 ↑ (상승 상징)
- 크기: 120px
- 위치: M 중앙 상단
```

### 컨셉 3: 동전 + AI 심볼
```
캔버스: 1024 x 1024 px
배경: Teal 그라데이션

심볼:
1. 동전 (외곽선)
   - 지름: 500px
   - 선 두께: 60px
   - 색상: White

2. AI 네트워크 (내부)
   - 3개의 점 + 연결선
   - 점 크기: 40px
   - 선 두께: 20px
   - 삼각형 배치

3. 상승 그래프 (하단)
   - 3개 막대 (낮음→높음)
   - 막대 너비: 80px
```

## 🎨 Figma / Canva 제작 가이드

### Figma 사용 시:
1. 새 파일 생성 (1024x1024)
2. 배경 사각형 → Fill: Linear Gradient
   - Color 1: #14B8A6 (좌상단)
   - Color 2: #0D9488 (우하단)
3. 라운드 처리: Corner Radius 227px
4. Pen Tool로 M자 산 그리기
   - Stroke: 48px, White
   - Cap: Round
   - Join: Round
5. Export → PNG (1024x1024)

### Canva 사용 시:
1. Custom size: 1024x1024
2. Elements → Shapes → 배경 사각형
3. Gradient: Teal → Dark Teal
4. Elements → Lines로 M자 그리기
5. Line width: 48px
6. Color: White
7. Download → PNG (Transparent background 체크 해제)
